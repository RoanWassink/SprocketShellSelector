# v0.3.0 armour simulator and APFSDS penetration test

Vibe coded with AI assistance. Select Vanilla/APFSDS/APHE or another existing shell profile in the armour simulator's new section. The original calibre slider remains full gun calibre: 125 mm with default APFSDS means a 27.5 mm penetrator. Penetration slider maximum is 2000 mm.

The manually chosen penetration is the synthetic test projectile's required RHA penetration. The native inverse AP formula calculates the corresponding speed for that profile's mass/diameter/K; it is not the real cannon muzzle velocity. Real firing and cannon preview still use the existing mass/velocity calculation. The detailed simulator uses exact float penetrator diameter/mass/K, while native colour sampling accepts only integer calibre and uses its own AP-mass approximation. Therefore fine overmatch/normalization differences between colours and detailed fragments are possible. The simulator retains native density/normalization handling to match the existing actual-shot route. Selecting another profile invalidates the cached simulation. APFSDS/APHE spall behavior uses the same scoped hooks as actual impacts.

APFSDS penetrationQuality is .45 in this test config (was .75). Native K = round(vanillaK / quality^(1/1.43)); native penetration is proportional to quality apart from ushort rounding/clamping. Therefore the user's approximate 1006 mm case becomes about 604 mm at otherwise unchanged geometry and velocity. No 125 mm exception, fixed penetration output or fixed 1650 m/s value is used. This is a calibration constant in the game's native AP model, not a validated physical long-rod model. Density/rod length/speed vary with settings and full gun calibre; actual real ammunition differs in geometry, strength, target properties and range.

Confirmed current native APIs: ArmourOverlayConfig.Draw and FloatProperty.SetLimits; ArmourOverlay.get_SampleSettings; ArmourOverlayPointerOperator.Update; CompoundStructure.Penetrate; constructors ArmourOverlaySampleSettings(ushort,float) and PenetratorInfo(float,float,float,float,ushort,Vector3,Vector3). Native constructor sets penetration limit 500, actual calibre range 20..250 mm on this installed build. Pointer update constructs an AP PenetratorInfo and invokes the damage model's Penetrate interface; CompoundStructure runs the same native fragment route as real shots. Native ComputeRequiredPenetrationSpeed is the inverse of ComputePenetration and takes diameter/penetration in mm. No speculative runtime reflection.
